How to play
  • A hidden code of 4 coloured pegs is drawn from 6 colours.
  • Fill the highlighted row and submit. Each guess is scored with key pegs:
  • White filled peg = right colour, right position.
  • Hollow peg = right colour, wrong position.
  • Key pegs are unordered — they never say which peg was right.
  • Repeated colours only earn as many key pegs as they appear in the code.
  • Crack it before the attempts run out.
